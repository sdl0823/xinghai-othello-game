# 星海九尾・黑白棋 MCTS 十關闖關對弈系統 (單機模組版)

本專案為完全模組化設計的單機版黑白棋 AI 遊戲，支援角色頭像棋子對弈、10 關階梯制解鎖、蒙地卡羅樹搜尋 (MCTS) 自適應演算法、存檔/記錄檔 (JSON 匯入匯出)，並預留未來擴充音效與動畫的專屬資料夾。

---

## 🎮 玩法與規則機制

1. **純棋盤沉浸介面**：
   - 移除了原設計師介面左右兩側繁複的調試滑桿與表格，畫面正中央專注呈現 **8x8 頭像棋盤** 與當前對決資訊。
   - 需要查看進階 MCTS 參數時，可點擊右上角「⚙️」開啟收納式的調試面板。

2. **獲勝解鎖關卡制 (預設 10 關)**：
   - 遊戲開始時**僅解鎖第 1 關**，第 2 至 10 關均帶有 🔒 鎖定圖示。
   - 玩家必須在第 N 關**獲得勝利**（黑白子結算大於守關 AI），系統才會自動解鎖第 N+1 關！
   - 點擊未解鎖關卡會提示鎖定資訊，無法跳關作弊。

3. **角色頭像棋子**：
   - 棋盤上的每一枚黑白棋子均為生動的角色頭像圖標（青藍光環代表玩家方，燦金光環代表 AI 方）。
   - 落子時伴隨頭像立體翻面動畫與落子音效。

4. **記錄檔與存檔系統**：
   - 點擊「💾 記錄檔」可隨時**儲存當前殘局**，隨後一鍵讀檔還原。
   - 支援「**匯出記錄檔 (.json)**」下載至電腦本機，方便備份或跨電腦攜帶。
   - 支援「**匯入記錄檔 (.json)**」上傳，隨時同步解鎖進度與生涯戰績。

## 🎵 如何在未來加入每關音樂與動畫？

1. **加入各關專屬音樂**：
   - 將你的音效檔依序命名為 `stage1.mp3`, `stage2.mp3`, ..., `stage10.mp3`。
   - 放入 `assets/audio/stages/` 資料夾內。
   - 切換關卡時，`audio_manager.js` 會自動載入並循環播放！

2. **自訂落子與勝利音效**：
   - 放入 `move.mp3`（落子）、`flip.mp3`（翻面）、`corner.mp3`（佔角）、`stage_clear.mp3`（獲勝過關）。
   - 放入 `assets/audio/sfx/` 資料夾內，系統將優先播放實體檔案。

3. **加入棋子翻轉動畫**：
   - 將動態圖檔放入 `assets/animations/pieces/`。
   - 在 `css/board.css` 的 `.disc.flip-anim` 引用對應的背景動畫或 GIF，即可實現豐富的角色動態效果。

## 🚀 離線單機執行方式

直接使用任一現代瀏覽器（Chrome, Edge, Firefox, Safari）雙擊打開 `index.html` 即可立即遊玩！
無需安裝任何外掛套件或架設本機伺服器。
